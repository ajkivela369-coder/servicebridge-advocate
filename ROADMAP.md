# Roadmap

## 0.2 — Better evidence structure

- Page-accurate PDF extraction and OCR confidence tracking.
- Timeline events linked to exact source spans.
- Claim-element matrix with “supported / partial / missing / conflicting” status.
- Duplicate and later-forward detection for email evidence.
- Encrypted local storage and configurable retention.

## 0.3 — Veteran and disability workflows

- Guard/Reserve duty-period ledger for active duty, ACDUTRA, INACDUTRA, and unresolved dates.
- VA favorable-finding and examination-adequacy extractors.
- Separate VA service-connection, rating, TDIU, and SMC workspaces.
- SSDI/APTD residual-functional-capacity and sustained-work matrix.
- ADA/504 accommodation request builder using minimum necessary disclosure.
- Deadline tracker that requires source and confidence for every date.

## 0.4 — Safety and evaluation

- Prompt-injection isolation for untrusted records.
- Citation entailment and unsupported-claim checks.
- Redaction review interface.
- Adversarial tests for legal-lane blending, source laundering, and invented facts.
- Accessibility testing for cognitive load, keyboard navigation, and screen readers.

## Later

- Encrypted multi-user case collaboration with explicit consent and role-based access.
- Connectors for user-authorized record stores.
- Format-only fine-tuning using synthetic cases, if evaluations show a real benefit.
- Jurisdiction/version registry for primary legal authorities.
