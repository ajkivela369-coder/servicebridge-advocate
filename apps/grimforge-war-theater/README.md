## Reference Theater

The initial theater link is:

https://youtu.be/vuBPKpoH_N0?si=hmCtxD8a8VNjlyvH

The reference is used only for broad production study: pacing, scale, shot rhythm, camera grammar, narration density, lighting, sound structure, and story rhythm. The app does not copy the source channel's characters, lore, dialogue, scripts, music, branding, or visual assets.

## Current workflow

Reference Theater → editable Reference Lens → Campaign Forge → War Bible → three-act battle spine → seven-beat Battle Grammar → Shot Forge → provider-aware Production Queue.

The built-in demo campaign and factions are original fiction.

## Shared production core

Future video generation, TTS, captions, sound mixing, continuity checks, QC, and final render should use the provider-neutral contracts in:

`apps/video-core/`

Provider-dependent states remain explicitly marked as not connected until a real provider is wired.
