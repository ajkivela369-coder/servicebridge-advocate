The four companion websites are deployed with an owner-only audience at this snapshot. Their metadata, branded thumbnails, canonical URLs, structured data, robots files, and sitemaps are prepared for public sharing; private pages are not claimed to be publicly indexed. The three new app plugins are private workflow packages using the existing Grim Forge Commander connection. They do not expose a separate public app backend or an app-scoped security boundary.

Local Elias is a general assistant. The hosted Elias evidence demo includes Evidence Auditor as its specialist workspace; the separate websites and plugins explain those roles without claiming identical local and hosted builds.


The machine-readable association record is [companion-sites.json](companion-sites.json). Source packages live under [plugins/](plugins/). The public-safe overview is maintained in [forge-ai-showcase](https://github.com/ajkivela369-coder/forge-ai-showcase/blob/main/COMPANION_SITES.md); this implementation repository is private and requires collaborator access.

All website source is versioned in its native Sites repository. Appending a plugin link was followed by source push and deployment of that exact source version. The landing pages contain fixed, fictional examples; they have no direct access to this laptop, private case records, or an AI model. SEO metadata is implemented; public indexing is pending public access.

Plugin source and branded assets are committed here to preserve the workflows. Version 1.0.0 creation and saved manifests were verified, but actual installation, fresh-chat skill loading, and app-specific model outputs remain separate acceptance steps. These app plugins reuse GFC's personal tool connection and are not separate permission boundaries.

For public distribution, replace personal bindings with per-user connection/setup and authenticated, isolated hosted services where applicable. See [PUBLIC_READINESS.md](PUBLIC_READINESS.md).
