## Current delivery

The installed local MCP server is version 2.0.0 and registers 46 tools. The owner-only secure tunnel connects ChatGPT to the intentionally no-auth local server. The branded installable plugin package is version 1.0.1. Its icon, website field, and existing app binding are preserved; the successful new-version upload is confirmed in the ChatGPT plugin UI.

The current native ChatGPT catalog still exposes the original 10 tools. Expanded tools are reachable through the existing program execution/local MCP relay route. Package metadata upload is not evidence that native discovery has refreshed. Server health and 75 qualification checks passed; full media production and every optional integration are separate acceptance work.

The three app-focused plugins use the same personal GFC connection. Their workflow instructions do not form separate permission boundaries. For public distribution, each user needs their own machine connection or an isolated authenticated backend. See [public readiness](../PUBLIC_READINESS.md).

This folder records the deployed integration and its build evidence; it does not claim a portable public server installer or include private runtime configuration, credentials, or case files.
