# StudyForge — Reference Lab + Forge Tutor

Source snapshot for the next StudyForge release.

## Signature features
- Import a public YouTube channel/video or website into **Reference Lab**.
- Extract only accessible, high-level teaching patterns (structure, pacing, diagrams, recap style, mnemonic strategy).
- Keep factual exam content grounded in official/manual/source material.
- Generate **original** study guides, visuals, flashcards, and QBank items using the selected presentation profile.
- Curated reference presets: Ninja Nerd, Osmosis, Medicosis Perfectionalis, Blood Bank Guy.
- Floating **Forge Tutor** copilot with access to the current guide, QBank, weak topics, and reference profile.
- Exam Coach scoring and weak-area remediation remain part of the workflow.

## Originality boundary
Reference sources are inspiration for abstract teaching/production patterns only. The app is intentionally designed not to reproduce scripts, proprietary questions, catchphrases, creator identity, artwork, or other distinctive protected expression.
