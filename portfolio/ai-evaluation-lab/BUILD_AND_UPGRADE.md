# AI Evaluation Lab build and upgrade

## October 9, 2026 - guided workflows v2.0.0

Preserved the original deployed source before updating all four shared browser workflows. Added plain-language purpose and audience, numbered steps, examples, Simple/Pro modes, validation, explicit review actions, draft recovery, human decisions and notes, readable Markdown reports, browser print/PDF, and Pro JSON export.

NeuroEval replaces the single hard-coded action-potential sample with eight independent educational topics and custom input. Concept mention coverage is labeled separately from factual accuracy. HealthQA uses configured wording flags and always requires human review. PairRank requires human ratings and never invents a rationale. CiteGuard separates lexical candidates from human source-support decisions.

The floating Elias guide provides built-in usage answers; no AI model is connected. Drafts stay in tab session storage; no input is sent to a backend or model service.

Deployment preserves the shared production URLs. Earlier Python projects and the pre-upgrade Windows source backup remain preserved. This static source directory is the current maintained browser implementation.
