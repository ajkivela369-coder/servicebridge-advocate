# Evidence Auditor Pro — Workspace Guide

Evidence Auditor Pro is organized around a simple idea: **start with Elias, then use the specialist tools only when you need them.**

- **Elias — Start Here:** Upload the source record once, ask evidence questions, inspect gaps/tensions, and create a first packet draft.
- **Review Readiness:** Check whether the sources are locatable and reviewable before relying on them.
- **Quote Integrity:** Verify proposed quotations against the loaded record.
- **Packet Integrity:** Check whether a packet remains traceable and internally coherent.
- **Coverage Gaps:** Find thin or missing evidence areas that deserve follow-up.
- **Packet Assurance:** Combine provenance, coverage, and quote checks into a transparent readiness screen.
- **Source Inventory:** Review the source set and page-level provenance.
- **Floating Copilot:** Use the lower-right ✦ icon on review pages for quick evidence questions without navigating away.

These tools organize evidence; they do not make legal, medical, rating, service-connection, or eligibility determinations. Human source verification remains required before external use.
