# Legacy Streamlit Evidence Auditor

This directory contains the previous Streamlit implementation of Evidence Auditor Pro.

It is preserved for reference, regression comparison, and reusable evidence-review logic. **It is not the current production build.** For the current Elias app, start at [`../00_CURRENT_APP/`](../00_CURRENT_APP/).

Legacy local launch:

```bash
python -m pip install -r requirements.txt
streamlit run dashboard.py
```

Do not commit private records or personally identifying case material to this public repository.
